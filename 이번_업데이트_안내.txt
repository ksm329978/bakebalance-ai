음료 재고 업데이트 2026-10-16
1. ZIP 압축을 풉니다.
2. GitHub bakebalance-ai 저장소의 Add file → Upload files를 누릅니다.
3. 압축 푼 폴더 안의 app, lib, public 등 파일과 폴더 전체를 업로드합니다. ZIP 자체나 바깥 폴더 한 개를 올리지 마세요.
4. Commit changes를 누릅니다.
5. Vercel의 bakebalance-ai 프로젝트 → Deployments에서 가장 위 배포가 Ready인지 확인합니다. Error면 오류 화면을 보내주세요.
6. 사이트에서 Ctrl+Shift+R을 누릅니다. 왼쪽 음료 재고·발주를 엽니다.
7. 기존에 재고를 저장한 브라우저라면 이팝청춘 기본 21품목 추가 버튼을 누릅니다. 기존 입력을 지우지 않고 같은 이름이 없는 품목만 추가합니다. 중복 품목은 확인 후 삭제하세요.
8. 현재고·조달기간·안전재고·구매 포장단위를 확인하고, 실제 잔당 사용량을 입력한 후 저장하세요. 단위 변경 시 자동환산하지 않습니다.
구매량은 현재고가 아닙니다. 사용기간 중간값으로 계산한 사용량은 잠정치입니다. 딸기청·티·탄산수는 추가 확인이 필요합니다.
